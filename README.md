# 🛍️ A Full Stack E-Commerce Mobile App

A modern full-stack E-Commerce mobile application built using React Native and Expo. This project includes 🔐 user authentication, 🛒 cart functionality, ⚡ backend API integration, and a clean 📱 mobile UI for both Android and iOS platforms.

---

## 🚀 Tech Stack

- ⚛️ React Native
- 📱 Expo
- 🟢 Node.js
- 🚂 Express.js
- 🔐 Clerk Authentication
- 🍃 MongoDB
- 🔗 REST API

---

## ✨ Features

- 🔑 User Authentication
- 🛍️ Product Listing
- 📄 Product Details Screen
- 🛒 Shopping Cart
- 👤 User Profile
- ⚡ Backend API Integration
- 📱 Cross Platform Support (Android & iOS)
